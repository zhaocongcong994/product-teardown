# Round 2：Agent 契约

本轮目标：识别产品创作/服务流程中实际出现的每一个 Agent，基于页面证据拆解每个 Agent 的输入信息、判断任务、工具调用、输出信息、全局上下文读写和下游交接关系。**本轮只形成"Agent 契约"，不要编写完整 System Prompt。**

## 一、重要边界

- 页面公开展示的"思考完成""规划完成"可作为产品暴露给用户的判断摘要
- 不要声称读取到了模型隐藏的思维链
- 不要把 Agent 的口头计划当成已执行的工具调用
- 只有看到资产变化、状态变化、工具结果或页面结果，才能确认动作已发生
- 无法确认的内容标记为"推断"或"未知"

## 二、识别实际出现的 Agent

按时间顺序寻找：当前回复属于哪个 Agent、何时加入流程、谁触发了它、接替了谁、完成后交给谁、是否会被重新调用、哪些步骤没有调用通常存在的 Agent。

先输出 Agent 清单。**不要预设 Agent 数量**，只记录有证据支持的 Agent。

## 三、每个 Agent 的输入检查六类来源

- **A. 用户当前输入**：原始需求、补充说明、风格/参数选择、参考素材、表单选择、满意/不满意、修改意见、中断或继续指令
- **B. 用户长期信息**：界面语言、会员/套餐状态、积分/额度余额、用户资产库、历史创建的资产、已保存的配置、默认偏好、项目历史版本、用户权限。页面有可见证据标"事实"，按机制判断可能存在标"推断"。不得查看或输出账号凭证及敏感身份信息
- **C. 当前项目的全局上下文**：逐项寻找页面证据（项目配置、需求文档/剧本、风格、资产列表及引用关系、当前模型和参数、任务状态、用户确认状态、失败状态、历史版本、已生成资产）。**不要默认这些字段都存在**
- **D. 上游 Agent 的输出**：上游是谁、传递了什么、当前 Agent 如何使用、修改上游内容后当前 Agent 是否需要重新执行
- **E. 平台公共资产、知识和规则**：风格库/模板库、模型能力列表、领域专业知识、内容安全规则、版权规则、计费规则、模型限制、提示词模板。页面明确出现标"事实"，行为推导标"推断"，无法确认标"未知"
- **F. 工具和系统执行结果**：生成结果、安全拦截错误、余额不足错误、用户中断事件、工具调用失败、状态写入失败、重试结果、资产地址或引用关系

## 四、拆解 Agent 的判断任务

不还原隐藏思维链，只总结页面可观察的"功能判断"。每个 Agent 至少检查：要解决什么问题、需判断哪些信息是否齐全、如何决定下一步、何时需向用户确认、何时可自动继续、何时必须停止、如何处理用户修改、如何处理工具失败、如何判断任务完成、是否真正验证了结果质量。

每条判断规则标记【页面事实】【合理推断】【尚未确认】。

## 五、拆解工具调用

为每个 Agent 输出工具表。页面没直接展示的工具**不要编造官方函数名**，使用功能性名称（如"读取项目上下文""生成主图""建立资产引用关系""检查余额"），并注明"功能命名，并非官方工具名"。

## 六、拆解每个 Agent 的输出（五类）

- A. 面向用户的输出：自然语言回复、计划说明、结果说明、错误解释、修改建议
- B. 页面交互输出：按钮、表单、选择项、确认卡片、错误提示、预览入口
- C. 资产输出：文档、图片、音视频、结构化数据、历史版本
- D. 全局上下文写入：新增/修改字段、状态变化、资产地址、引用关系、用户确认结果、任务成败状态
- E. 下游交接：触发哪个 Agent、传递哪些字段或资产、下游开始条件、是否需用户确认后才能交接

## 七、为每个 Agent 输出 I/O 契约卡（固定格式）

```
Agent：名称
1. 核心目标
2. 触发条件
3. 输入信息（来源类型：用户当前输入/用户长期信息/项目全局上下文/上游 Agent 输出/平台公共资产/工具或运行时结果）
4. 可观察判断
5. 调用工具（使用工具表）
6. 输出信息（用户回复/页面组件/结构化字段/视觉或音视频资产/状态/下游任务）
7. 全局上下文读写（字段或对象、读取/写入、生产者、消费者、更新时机、证据等级、证据）
8. 完成条件
9. 异常与重试
10. 尚未确认的问题
```

## 八、建立全局数据流

完成所有 Agent 卡片后输出数据传递表，重点寻找：
- 同一数据是否有多个版本；聊天状态与画布状态是否一致
- 资产是否通过稳定引用关联到下游；修改上游后下游资产是否自动失效
- 是否存在只写不读或只读不写的字段
- 是否存在 Agent 口头说完成但全局状态没有更新的情况

## 九、最终交付（HTML 可视化页面）

依次输出：查看范围与证据缺口 → Agent 清单 → 每个 Agent 的 I/O 契约卡 → 工具总表 → 全局上下文字段表 → 数据生产者—消费者关系表 → Agent 输入—判断—工具—输出—交接流程图（含每个 Agent 的能力边界备注）→ 事实、推断和未知事项清单 → 最值得继续验证的五个问题。

完成后**不停顿**，直接进入 Round 3。
